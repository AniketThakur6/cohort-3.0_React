# React Learning Journey

![React](https://img.shields.io/badge/React-Learning-61DAFB?logo=react&logoColor=white)

Welcome to my React learning workspace. This repository collects the small projects I have built while learning how React components, state, props, events, and styling work together.

## Projects

| Project | Description | Tech / Focus |
| --- | --- | --- |
| `todo-app` | A task manager for adding, completing, and organizing tasks. | `React` `Vite` `Tailwind CSS` |
| `counter` | A practice project for learning state updates and user interactions. | `React` `useState` |
| `first-card` | An early UI exercise focused on building components and layouts. | `React` `Components` |

## What I Am Learning

- Building reusable, component-based user interfaces
- Managing data with React's `useState` hook
- Passing data between components with props
- Handling form input and user events
- Styling responsive interfaces with Tailwind CSS

## Featured Project: Todo App

The Todo app is the most complete project in this workspace. It helps me practice a real component structure while supporting these features:

- Add new tasks
- Mark tasks as complete
- View active and completed tasks separately
- Work with state-driven UI updates

## Purpose

This is more than a collection of finished projects. It is a record of my progress as I move from simple React experiments to more structured, interactive applications.

## Run the Todo App

From this repository's root folder, run:

```bash
cd todo-app
npm install
npm run dev
```
